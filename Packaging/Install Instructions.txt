Install Stash

1. Copy Stash.app into your Applications folder.
2. Open Stash from Applications.

If macOS says Stash cannot be opened because it is not from an identified
developer, Control-click Stash in Applications, choose Open, then confirm.

For global keyboard shortcuts, allow Stash to monitor keyboard input under
System Settings > Privacy & Security > Input Monitoring (called Device Control
& Access on some macOS versions). Synthetic paste may also require device or
accessibility permission. Stash retries automatically after access is enabled.
You can use Show Clipboard HUD in the Stash menu-bar menu in the meantime.

Stash runs from the menu bar. Hold Option to show the clipboard HUD.
